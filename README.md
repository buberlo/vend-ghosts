# Vend Ghosts

> Run a haunted vending machine where snacks calm spirits.

Vend Ghosts is a cozy arcade game where you manage a haunted office vending machine and dispense snacks to restless ghosts. Each ghost has a craving, fear, and grudge, and the wrong snack turns their wisp into a sticky jam incident. You earn ectoplasm by reading subtle cues and avoiding a full-blown after-hours haunting.

## Features
- 20 ghost personalities with craving, fear, and grudge values
- Snack inventory system where items expire into cursed leftovers
- Haunting meter that rises from wrong snacks and missed shifts
- End-of-shift report with ghost satisfaction and ectoplasm payout

## Stack
- TypeScript
- PixiJS
- Howler.js
- Firebase

## Getting started
```
npm install && npm run dev
```
